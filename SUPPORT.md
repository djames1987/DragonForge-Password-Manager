# Support

This repository is the historical pre-migration standalone DragonForge Password Manager baseline. Active development, current bug reports, feature requests, and support belong in [DragonForge Security Suite](https://github.com/djames1987/DragonForge-Security-Suite).

Use this repository's issue templates only for defects or documentation problems specific to the historical baseline. Do not post passwords, Account Secrets, recovery material, OTP seeds, tokens, private keys, vault contents, personal data, or sensitive exploit evidence.

Security vulnerabilities must use the private process in [SECURITY.md](SECURITY.md). Unsolicited code contributions are not currently accepted; see [CONTRIBUTING.md](CONTRIBUTING.md).
