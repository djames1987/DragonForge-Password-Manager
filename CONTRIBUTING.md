# Contributing to DragonForge Password Manager

This repository is the historical pre-migration source and verified baseline for DragonForge Password Manager. Active Password Manager development now occurs in `djames1987/DragonForge-Security-Suite`.

DragonForge source is visible for evaluation, portfolio review, security review, and reference, but it is not open source.

## Current contribution policy

Unsolicited code contributions and pull requests are not currently accepted here. Contributor licensing/assignment terms and a CLA policy have not yet been established, and new Password Manager development belongs in the canonical Security Suite repository.

Please do not submit source code, patches, artwork, or other copyrightable implementation material unless David James has explicitly invited that contribution and supplied the applicable written terms.

Issue reports and non-code feedback should target the canonical Security Suite when they concern current Password Manager development. Security-sensitive reports should follow the applicable security guidance rather than being disclosed publicly.

Submitting an issue or other feedback does not grant a license to DragonForge source code or alter the rights described in `LICENSE`.

## Third-party material

Existing third-party components retain the rights and obligations of their own licenses. Do not submit third-party material unless its origin and license are known and compatible with the project.
